# contracts/

契約のひな型。**すべて法務の確認を受けていない草案**で、そのまま使わない。
どれを誰と結ぶか、責任をどう分けるかの議論は
[`docs/1-requirements/licensing.md`](../docs/1-requirements/licensing.md)。

| ファイル | 契約 | 誰と誰 | いつ |
|---|---|---|---|
| `early-access-licence.md` | A 先行利用許諾 | ライセンサー → 先行利用者 | 正式リリース前。無償、フィードバックが対価、実投稿は3条件つき |
| `master-licence.template.md` | B マスターライセンス | ライセンサー → ライセンシー | 正式版。フォークと運用を許す。対価は選ぶ |
| `tenant-terms.template.md` | C テナント利用規約（チェックリスト） | ライセンシー → テナント | ライセンシーが第三者にアカウントを運用させるとき。B にテナント条項を付けた場合のみ |

`LICENSE`（リポジトリ直下）は契約ではなく通知。どの階層にどの契約が当たるかを、フォークした人に知らせる。

## 契約とソフトの対応

契約が言うことは、ソフトが実際に残す記録を指せなければならない。
その対応表は `licensing.md` 8節。ソフト側を変えたら、そこと該当する条項を見直す。
