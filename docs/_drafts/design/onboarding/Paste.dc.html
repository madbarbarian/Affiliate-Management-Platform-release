できた設定を、自分の控えに貼ります

ここまでの答えが、下の1枚になりました。これを自分の控えに貼ると、いまの内容で動き始めます。

platform.config.yaml

company:
  name: "モーニング工房"
  operator: "あなたの名前"

ventures:
  - id: main
    name: "朝の道具"
    niche: "朝の支度が10分速くなる道具"
    audience: "6時台に起きる共働き世帯"
    market: jp          # 日本の広告規制に従います
    timezone: Asia/Tokyo
    voice:
      person: "です・ます"
      avoid: ["神", "革命", "圧倒的"]
    cadence:
      postsPerDay: 1    # 最初の3日は1本です
      cycleStartsAt: "06:30"

tracking:
  baseUrl: "https://amp-….workers.dev"  # ← あなたのアドレス

1行だけ、書き換えです

tracking: の baseUrl: は元の設定にもうあります。 足すのではなく、書き換えてください。 同じ名前が2つあると設定が読めません。
ここを書き換えるまで、投稿のリンクは押されても記録されません。

貼る場所

この画面はあなたの設定を勝手に書き換えません。 設定はあなたのもので、変更の履歴もあなたの控えに残ります。だから、貼るのはあなたです。 

1 上の「コピーする」を押します
2 あなたの控えを開く を押します（新しいタブで開きます）
3 貼り付けて、保存します
4 1〜2分で、この画面が新しい設定で開き直します

あとから変えられます。 ニッチも文体も投稿数も、同じ控えを開いて直して保存するだけです。 ここで完璧にする必要はありません。
