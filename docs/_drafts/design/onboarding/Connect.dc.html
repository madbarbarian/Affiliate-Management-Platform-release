トークンを取るまでの手順

1. Meta開発者コンソールでアプリを作ります（用途は Threads API）
2. 権限に Threads Basic と Threads Content Publishing を追加します
3. 自分のプロアカウントを接続して、短期トークンを取ります
4. 長期トークンに交換します（有効期限は60日）
4の交換ページは、この画面のリンクから直接開けます。

よくある失敗

個人アカウントのまま — プロアカウントに切り替える必要があります
短期トークンを貼った — 1時間で切れます。長期トークンに交換してください
権限が足りない — 上の手順のどれが欠けているかを具体的に示します

トークンは .env.local にだけ保存されます。 設定ファイルにも、この画面にも残りません。 .env.local は、コードを共有しても一緒には配られないファイルです。
