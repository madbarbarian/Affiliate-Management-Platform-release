# 用語集

日本語の文書（要件定義、導入手順、設計ノート、画面設計）で使う語を1か所に固定する。
コードの識別子（`venture`、`offer`、`console`）は英語のまま変えない。文書側だけを揃える。

| 文書で使う語 | 意味 | コード上の名前 | 使わない言い方 |
|---|---|---|---|
| **運用アカウント**（文脈が明らかなら**アカウント**） | 1つのニッチ・読者・文体・市場を持つ、独立に学習する運用単位。`platform.config.yaml` の `ventures[]` の1要素 | `venture` | ベンチャー、案件（こちらは下の意味に限る）、チャンネル |
| **案件** | ASP から受ける個々のアフィリエイト商材。ランディングURL・単価・通貨・対象市場を持つ | `offer` | オファー、商材 |
| **運用者** | 1日2回、提案にOKを出して投稿順を決める人 | `operator` | オペレーター |
| **ライセンシー** | リリースリポジトリをフォークして初期設定し、運用する事業者 | `licensee` | — |
| **承認画面** | 運用者が2つの判断をするブラウザ画面。`amp console` で起動する。トラッキングのリダイレクト `/go/` も同じサーバが配信する | `console` | 承認コンソール、管理画面（設定は置かないので） |
| **承認**（①企画の承認、②投稿の承認と順番） | 機械が止まって人間を待つ2か所 | `gate` | ゲート |
| **文体** | 一人称・トーン・使う言い回し・使わない言い回し | `voice` | 声 |
| **参考投稿** | 導入時に貼る「良いと思う投稿」5本。リサーチ担当が初期の型を抽出する材料 | `swipe` | スワイプ |
| **初期投入（由来）** | 参考投稿や他アカウントの集計から入った型であること。自分の実績ではないと分かるように監査ログに残す | `seeded` | 借り物 |
| **計測経路** | 投稿 → 反応 → リンク → クリック → 成果 → 報酬 が全部戻ってくる状態。`doctor` が `measurement:` として検査する | `measurementChain` | 鎖 |
| **概況書** | 運用アカウント1つの90日集計。買い手・ライセンシー・運用者が同じものを読む | `dossier` | 調書 |
| **全アカウント一覧** | ライセンシーが全運用アカウントの状態と滞留を見る画面。判断はしない | `portfolio` | ポートフォリオ画面 |
| **探索担当** | 週1回、全アカウントの集計から次に試す運用アカウントを提案する7つ目の役割。日課には入らない | `scout` | スカウト |
| **アカウント提案** | 探索担当が出す1件。仮説・根拠・リスク・最初の3本・やめる条件を持つ。採用しても設定は人が貼る | `VentureProposal` | 提案書 |
| **思想** | `company.principles`（どう考えるか）と `company.boundaries`（何をしないか）。全役割のブリーフに入る文章。規制ではない | `principles` / `boundaries` | ビジョン、ポリシー（こちらは `policy` の訳語） |
| **先行利用（者）** | 正式リリース前に使ってもらい、壊れ方を報告してもらう人 | — | パイロット |
| **停止** | `amp pause`。何も走らず何も出ない。捨てない、遅らせる。緊急・全体・閉じる側に倒れる | `pause` | 緊急停止（緊急でなくても使うので） |
| **非アクティブ** | 運用者が1アカウントを切った状態。動かず出ないが、学んだこと・履歴・成果は残り、再開は1クリック。判断・個別・開く側に倒れる | `deactivated` | 削除、停止（別物） |
| **見直し候補** | 全アカウント一覧が数字から付ける印。切るのは人 | `review` | 警告 |
| **やめられる** | 途中で導入を中断しても損がないこと | — | 帰れる |

## 固有名詞はそのまま

- **Meta開発者コンソール** — Metaの製品名。承認画面と混同しないよう、必ず「Meta」を付ける。
- **`amp console`** — コマンド名。文書内でコマンドを指すときはコードスパンで書く。
- **Threads / ASP / 景表法 / ステマ規制** — そのまま。

## 揃え方

- 一文の中で同じものを2つの語で呼ばない。特に「案件」は必ず案件（offer）の意味でだけ使う。
  運用単位を指すときは「運用アカウント」か、文脈が明らかなら「アカウント」。
- 英語の文書（`architecture.md` など開発者向け）は `venture` / `offer` のまま。
  日本語文書で初出時に併記するなら `運用アカウント（venture）` の形。
